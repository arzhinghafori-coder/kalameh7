کلمه | KALAMEH — نسخه بازیکنان بدون پنل مدیریت
================================================

محتویات:
- index.html: صفحه اصلی بازی
- style.css: ظاهر واکنش‌گرا
- app.js: بازی آزاد، چالش روزانه فارسی و انگلیسی، ثبت‌نام، ورود، پروفایل و برترین‌ها
- config.js: تنظیمات ثابت و عمومی اتصال Supabase
- بخش تنظیمات داخل سایت: انتخاب ۵ تم رنگی و حالت روشن، تاریک یا مطابق دستگاه
- supabase_setup.sql: جداول و توابع دیتابیس

۱) اتصال Supabase
1. از Supabase > Project Settings > API مقدار Project URL و کلید عمومی anon/publishable را بردار.
2. فقط یک‌بار در فایل config.js مقدار supabaseUrl و supabaseAnonKey را تنظیم کن؛ این مقادیر همراه پروژه ذخیره می‌شوند و دیگر در صفحه بازی فرم تنظیم اتصال نمایش داده نمی‌شود.
3. هرگز service_role یا Secret key را داخل فایل‌های سایت قرار نده.

۲) راه‌اندازی دیتابیس
1. در Supabase، SQL Editor را باز کن.
2. محتوای supabase_setup.sql را اجرا کن. اگر پروژه از قبل داده دارد، قبل از اجرای مجدد پشتیبان بگیر.

۳) انتشار با GitHub Pages
1. فایل‌ها و پوشه‌های داخل kalameh_site را مستقیماً در ریشه مخزن GitHub قرار بده؛ خود پوشه kalameh_site را به‌عنوان یک پوشه تو در تو آپلود نکن.
2. مطمئن شو index.html در ریشه مخزن قرار دارد.
3. در Settings > Pages، گزینه Deploy from a branch را انتخاب کن؛ شاخه main و پوشه /(root) را تنظیم و ذخیره کن.
4. پس از انتشار، آدرس GitHub Pages در همان صفحه نمایش داده می‌شود.

رفتار سایت:
- بازیکن با نام کاربری و رمز خودش ثبت‌نام یا وارد می‌شود.
- رکورد بازی، تعداد برد و باخت، بهترین تعداد حدس و سابقه بازی ذخیره می‌شود.
- چالش روزانه برای هر زبان واژه ثابت همان روز دارد و نتیجه آن در همان مرورگر فقط یک‌بار در روز ثبت می‌شود.
- بخش مسابقات از رابط سایت حذف شده است؛ جدول برترین‌ها باقی مانده است.
- پیوند تلگرام @KaLaMeh7 در پایین سایت قرار دارد.
- پروفایل بازیکن شامل سطح، آمار و تاریخچه است.
- بخش تنظیمات شامل ۵ تم رنگی منو و حالت روشن، تاریک یا هماهنگ با دستگاه است.
- انتخاب تم و حالت نمایش به‌صورت خودکار در مرورگر ذخیره می‌شود.
- رابط فارسی راست‌چین و رابط انگلیسی چپ‌چین است.

این بسته عمداً پنل مدیریت و تابع Edge مخصوص مدیریت را حذف کرده است. حذف پنل از فایل‌های سایت، حساب‌های Supabase Auth موجود یا داده‌های بازیکنان را حذف نمی‌کند.

نکته امنیتی: این نسخه از توابع RPC موجود در SQL استفاده می‌کند. برای امنیت بالاتر، محدودسازی نرخ درخواست و اعتبارسنجی کامل نتیجه بازی در سمت سرور توصیه می‌شود.
